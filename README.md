# Ben 10 Fan Page 👽⌚

Welcome to the Ben 10 Fan Page project! This website showcases various alien transformations, watchfaces, and sound effects from the Ben 10 universe.

## 🚀 Live Demo
Check out the live site here: [Ben 10 Fan Page](https://rahul-aththanayaka.github.io/ben10-fanpage/)

## 🛠️ Features
* Interactive alien transformation page
* Sound effects and custom watchfaces
* MySQL Database structure included (`omnitrix_db_2.sql`)

## 💻 Technologies Used
* **Frontend:** HTML5, CSS3, JavaScript
* **Database:** MySQL
